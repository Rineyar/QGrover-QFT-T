# QGrover-QFT-T
Проектная/курсовая работа по реализации симуляции квантовых состояний, алгоритма Гровера, квантового преобразования Фурье.
Так же реализивана визуализация амплитуд по шагам выполнения программы. (WIP)

## Квантовые операции:
- Гейт Адамара - принцип создания Квантового вентиля. Создание суперпозиции всех допустимых состояний по принципу 1/sqrt(N)
- - Квантовый вентиль - 2^n --> N амплитуд (квантовых вентилей), т.е. допустимых состояний кубитов.
- Окарул - служебная функция для алгоритма Гровера. Используется для инвертирования значения выбранного x0, для диффузионного роста.
- Оператор диффузии - служебная функция для алгоритма Гровера. Вычисление амплитуды по принципу 2*mean - amp. Т.е. от удвоенного среднего всех амплитуд отнимается текущая и таким образом получается её новое состояние. Это обеспечивает проборциональное уменьшение всех амплитуд, кроме инвертированной Оракулом.
- QFT - квантовое преобразование Фурье, используется для разбиения дискретного набора амплитуд на упорядоченные амплитуды, из которых может быть получен изначальный набор.
- QFT^T - обратное преобразование фурье, выполняет инвертированное вычисление, что позволяет получить изначальный набор амплитуд из упорядоченных.
- - Реализован на основе FFT (быстрого преобразования Фурье) и допустим для квантовых вычислений благодаря гейту Адамара.

## Алгоритм Гровера
- Инициализация суперпозиции - определение состояния всех амплитуд по гейту Адамара.
- Выполнение - вычисление PI/4*sqrt(N) итераций алгоритма.
- Структура алгоритма - применение Оракла к искомому значению (x0) с целью роста амплитуды этого значения при последующей диффузии. Диффузирования квантового состояния для перераспределения вероятностей.
- Последующее измерение - используется для определения вероятности после выполения алгоритма Гровера. Реализовано через определение случайного числа, и последовательное суммирование суперпозиционных вероятностей. Когда сумма вероятностей превосходит случайное определение, это считается определением x0.

## Оптимизация
- Затраты памяти при n = 20 определяется 1 048 576 состояний, что требует 16 * 2^20 памяти, что равняется 16МБ, + 1МБ операционной памяти, с учётом запаса по принципу 1/3, требуется ~40МБ памяти, из которых использутся дай боже 20МБ. Т.е. человеческим языком всё хорошо.
- Так же реализованно разряженное хранение апмлитуд в векторе, с требуемым порогом отсечения в 1e-10. (Что в целом не нужно с учётом потребления памяти и того, что при алгоритме Гровера и QFT значение амплитуд не может быть ниже 1e-10, проверенно множеством тестов, г.н. Филиппов ошибся с порогом).
- Алгорим гровера имеет скорость выполения O(N * sqrt(N)). sqrt(N) итераций, N каждая итерация для вычисления среднего значения и последующего вычисления каждой амплитуды.
- QFT реализовано через FFT и имеет скорость O(N * log2(N)). Вообще стандартный QFT выполняется за O(N^2), но в текущих реалиях при n = 20 O((2^20)^2) будет невыполнимым. Поэтому он был реазизован как реализован.

### Итоговые значения
Условно 2^n = N
- Затраты памяти:
- - O(2^n) = O(N) ~-> 16МБ худший случай
- Скорость выполнения:
- - O(2^n * sqrt(2^n)) = O(N * sqrt(N)) - алгоритм Гровера !-> 10^9 худший случай
- - O(n * 2^n) = O(N * log2(N)) - QFT ~-> 20 000 000 худший случай

## Смысловая нагрузка
### Алгоритм гровера
Квантовый алгоритм используемый для решения задач путём полного перебора используя кубиты. Т.е. находит решение f(x) = 1.
В данном случае реализованя симуляция алгоритма для нахождения вероятности на равновероятностной суперпозиции.
#### Простыми словами
Алгоритм Гровера работает как усилитель нужного ответа.
Сначала все варианты имеют примерно одинаковую вероятность. Потом оракул помечает правильный вариант, меняя знак его амплитуды. Сам по себе этот знак ещё не даёт ответа, но после этого применяется диффузия — отражение всех амплитуд относительно их среднего значения.

Из-за этого амплитуда правильного варианта становится больше, а амплитуды неправильных вариантов постепенно уменьшаются. Если повторить такую пару действий несколько раз, вероятность получить правильный ответ при измерении становится большой.
